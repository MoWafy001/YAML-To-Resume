# Reference Example

This directory contains a `resume.yaml` file that serves as a complete reference for the YAML-To-Resume schema.

## Usage

You can use this file as a starter template for your own resume:

```bash
cp examples/00-reference/resume.yaml my_resume.yaml
```

Or build it directly to see how it looks:

```bash
yaml-to-resume examples/00-reference/resume.yaml
```

## Key Features Shown

- **All Block Types**: Header, Summary, Skills, Experience, Education, and Projects.
- **Formatting**: Multi-line strings, lists, and nested objects.
- **Metadata**: Custom output names, colors, and template selection.
